# Consumidor de API de Clima (Weather App)

Uma aplicação em Python desenvolvida para consultar dados meteorológicos em tempo real de qualquer cidade do mundo utilizando a API REST da **OpenWeatherMap**

## Funcionalidades
- **Consulta em Tempo Real:** Obtém temperatura (°C), umidade relativa do ar e condição climática atualizada.
- **Internacionalização:** Respostas e descrições formatadas em Português do Brasil (`pt_br`).
- **Tratamento de Exceções:** Validação de entradas e tratamento de erros HTTP (ex: cidade não encontrada ou falhas de conexão).

## Tecnologias Utilizadas
- **Python 3.x**
- **[Requests](https://requests.readthedocs.io/):** Para requisições HTTP e consumo de API REST.
- **[OpenWeatherMap API](https://openweathermap.org/api):** Provedor dos dados de clima.
